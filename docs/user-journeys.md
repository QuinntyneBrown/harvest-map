# User Journeys

The main flows covered by the HTML mocks in [`docs/mocks/`](mocks/index.html), ordered from most essential and highest value to least.

| Journey | Description |
| --- | --- |
| Answer the questions | Read answers to the four core research questions. |
| Run research | Start a web research run to find organizations. |
| Review a finding | Accept or reject a research finding before saving it. |
| Browse organizations | List, filter and select organizations serving Christian youth. |
| View an organization | See an organization's details, people and linked problems. |
| Create or edit an organization | Fill in the organization form and save changes. |
| Manage people | Browse, add, edit and delete key people. |
| Manage problems | Browse, create, edit and delete problems organizations target. |
| Link a problem | Attach a problem to an organization. |
| Explore the Field | See questions, most impactful work and latest research at a glance. |
| Sign in | Enter credentials and land on the Field home page. |
| Explore the map | See where organizations are and where gaps remain. |
| Search | Find organizations, people, problems and findings in one place. |
| Import from CSV | Upload a CSV file to add records in bulk. |
| Delete an organization | Confirm and remove an organization record. |
| Export data | Download records as a file. |
| Read notifications | View and mark research and system notifications as read. |
| Reset password | Request a reset link, then set a new password. |
| Recover from errors | See offline, not found, forbidden and server error pages. |
| Use the command palette | Jump to pages and actions from the keyboard. |
| Change settings | Update account and app preferences. |
| Sign out | Confirm sign-out from the account menu. |
