Foundation

Color

Warm stone neutrals and one ember accent. Every pair passes WCAG 2.2 AA in both themes.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Colour is quiet so content and whitespace lead. One accent (ember) marks the primary action, current navigation and highlights. Status colours always come with an icon and a word.

Usage

  • Accent is ember-700 on light (5.2:1 on white), ember-300 on dark.
  • Never use a primitive in a component.
  • AI tags use accent-subtle; Moonshot tags use warning-bg.
  • Gold (warning-icon) is reserved for rank 1.
