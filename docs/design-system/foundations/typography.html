Typography

Inter (Segoe UI Variable fallback), nine sizes, tight display, 16px body. Minimal text, big numbers.

WCAG 2.2 AAStatus: stableSince v1.0

  • Roles

Overview

Headings are bold and tight; numbers carry the story (tabular, h2 size on question cards). Copy is short. Headings use text-wrap: balance, paragraphs pretty.

Usage

  • Body is 16px; nothing below 12px.
  • Display (48px) only for the Field hero and error codes.
  • Line length capped at --layout-measure (65ch).
  • Numbers: tabular-nums, thousands separators.

Accessibility

  • All sizes in rem; reflows at 200% zoom.
  • Text spacing overrides (1.4.12) do not clip: no fixed heights on text containers.
