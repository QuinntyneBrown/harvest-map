Foundation

Responsive

Mobile-first; tested at 360, 768 and 1280px with no horizontal page scroll.

WCAG 2.2 AAStatus: stableSince v1.0
  • Overview
  • Per component
  • Touch

Overview

  • Base styles are for 360px.
  • 48rem adds inline nav and wider gutters; 64rem adds the full brand, 2:1 detail grids and 64px margins.
  • Phones: dialogs become bottom sheets, entity cards wrap, map popovers dock below.

Per component

Component< 768px≥ 1024px
Top barMenu button + drawerFull nav + brand

Touch

  • Targets ≥ 24px; primary mobile actions ≥ 44px.
  • Hover-only affordances (row checks, lifts) are always visible or unnecessary on touch.
