Elevation

Four shadows and a z-order scale. Cards barely float; dialogs clearly do.

WCAG 2.2 AAStatus: stableSince v1.0
  • Overview
  • Surfaces
  • Z-order

Overview

Flat by default. Hover lifts cards from level 1 to 2. Menus 3, dialogs 4.

Usage

  • Dark theme: raised surfaces get lighter; shadows get darker and larger.
  • Never set a raw z-index.
