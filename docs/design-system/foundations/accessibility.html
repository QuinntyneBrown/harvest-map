Foundation

Accessibility

WCAG 2.2 AA by construction: contrast in tokens, one focus ring, native elements first.

WCAG 2.2 AAStatus: stableSince v1.0
  • Commitments
  • Testing
  • Component contract

Commitments

  • Text ≥ 4.5:1, UI edges and focus ≥ 3:1 in both themes (checked).
  • One 2px focus ring with offset; never removed.
  • Skip link and landmarks on every page.
  • Targets ≥ 24px.
  • Every form error says how to fix it; summary links to fields; focus moves to the summary.
  • Status is never colour alone.
  • Toasts live in status regions; errors persist.
  • Dialogs trap focus, close on Escape, return focus; page behind is inert.
  • All motion respects reduced motion.
  • Native elements first; ARIA follows APG patterns named on each component page.

Testing

  • Run check_contrast.py and check_design_system.py.
  • Tab through one page, one dialog and one toast.
  • Check 200% zoom and 320px reflow.
  • Test with NVDA + Chrome.

Component contract

Every component page answers: role and pattern, keyboard, focus, labelling, contrast pairs, motion, touch.
