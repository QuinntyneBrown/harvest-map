Foundation

Layout

Top-bar shell, 76rem container, 4/8/12 columns, wide margins.

WCAG 2.2 AAStatus: stableSince v1.0
  • Overview
  • Grid
  • Page templates
  • Usage
  • Tokens

Overview

No sidebar: the top bar carries navigation, the page gets the width. Detail pages split 2:1 with an aside from 1024px.

Page templates

  • Shell: top bar + main.container.app-main.
  • List: header, toolbar, entity list, pagination.
  • Detail: breadcrumb, header with mark, .detail 2:1 grid.
  • Form: 44rem card.
  • Auth: centred 26rem card, no top bar.
  • Hero: Field page with the WebGPU field.

Usage

  • Use .container for every page.
  • Never scroll the page sideways; tables and maps contain their own overflow.
