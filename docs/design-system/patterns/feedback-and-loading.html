Feedback & loading

Every action answers within 100ms; skeletons for pages, busy buttons for actions, progress for runs.

Overview

Choose the quietest feedback that is still seen.

When to use

  • Inline status for saves.
  • Toast for completed actions with Undo.
  • Banner for long runs and connectivity.
  • Dialog only for decisions.

Structure

Saved · just now
Live composition.
HTML
<div class="stack"><span class="inline-status inline-status--success">Saved · just now</span><div class="progress" role="progressbar" aria-label="Run" aria-valuenow="62" aria-valuemin="0" aria-valuemax="100" style="width:16rem;"><div class="progress__bar" style="--value:62%"></div></div></div>

States

  • < 300ms nothing; skeleton for first load; determinate progress when the length is known; optimistic accept/reject with undo.

Responsive

  • Toasts span the width on phones.

Accessibility

  • Live regions for status; never steal focus.

Content

  • Say what happened and what's next.
