Pattern

Notifications

Toast for what you did, banner for what is happening, centre for what happened while away.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Three channels, no duplicates.

When to use

  • Toast: own action, 8s, Undo.
  • Banner: runs, offline, workspace changes.
  • Notification centre: history with unread dots.

Structure

Run #48 running · 62%
Live composition.
HTML
<div class="alert alert--info banner" role="status" style="width:100%;"><span class="dot dot--pulse" aria-hidden="true"></span><div class="alert__body"><span class="alert__title">Run #48 running · 62%</span></div></div>

States

  • info · success · warning · danger (persistent) · with action · stacked (max 3) · persistent banner.

Responsive

  • Toasts full width on phones.

Accessibility

  • Polite for status, assertive for errors.

Content

  • Past tense, specific.
