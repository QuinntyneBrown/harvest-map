Pattern

Dialogs & overlays

Dialog for decisions, drawer for navigation, popover for previews, page for long forms.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

One overlay at a time; palette replaces, never stacks.

When to use

  • Dialog: confirm, short form, review.
  • Drawer: phone nav.
  • Popover: map pin.
  • Page: anything with more than five fields.

Structure

Sign out?

Live composition.
HTML
<div class="dialog__panel" style="position:relative;max-width:24rem;animation:none;"><div class="dialog__header"><h3 class="dialog__title">Sign out?</h3></div><div class="dialog__footer"><button class="btn" type="button">Cancel</button><button class="btn btn--primary" type="button">Sign out</button></div></div>

States

  • Default · busy · invalid · failed (inputs kept) · success (stay open to add another) · scroll.

Responsive

  • Bottom sheets under 640px.

Accessibility

  • APG Dialog; inert page; return focus.

Content

  • Title is a question for confirmations.
