Overview

Filter chips use aria-pressed. They press with a spring scale.

Anatomy

  1. Pill32px, 1px border
  2. LabelLabel text

Variants

Variants change emphasis or content, never meaning.

Tag
Filter off/on; removable.
HTML
<button class="chip" type="button" aria-pressed="false">Youth</button><button class="chip" type="button" aria-pressed="true">Moonshot</button><span class="chip">Tag <button class="remove" type="button" aria-label="Remove tag">×</button></span>

Sizes

One size (32px).

States

Pointer and focus states are forced with data-state; real pages use the pseudo-classes.

VariantDefaultHoverFocusPressedDisabled
Chip

Both themes

Responsive behaviour

  • Chip rows wrap via .cluster.

Theming

Reads --color-accent-subtle, --color-fg-accent, --color-border-strong. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
