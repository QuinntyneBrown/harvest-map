Overview

Use determinate whenever the queue length is known.

Anatomy

  1. Track8px, --color-bg-subtle-hover
  2. BarAccent

Variants

Variants change emphasis or content, never meaning.

Thin, indeterminate, success.
HTML
<div class="progress progress--thin" role="progressbar" aria-label="Thin" aria-valuenow="62" aria-valuemin="0" aria-valuemax="100" style="width:12rem;"><div class="progress__bar" style="--value:62%"></div></div><div class="progress progress--indeterminate" role="progressbar" aria-label="Indeterminate" style="width:12rem;"><div class="progress__bar"></div></div><div class="progress progress--success" role="progressbar" aria-label="Done" aria-valuenow="100" aria-valuemin="0" aria-valuemax="100" style="width:12rem;"><div class="progress__bar" style="--value:100%"></div></div>

Sizes

8px default, 4px thin.

States

Pointer and focus states are forced with data-state; real pages use the pseudo-classes.

Variant0%62%100%
Bar

Both themes

Responsive behaviour

  • Full width of its card.

Theming

Reads --color-accent, --color-bg-subtle-hover. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).

Both themes
