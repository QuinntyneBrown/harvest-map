Responsive behaviour

  • Long URLs wrap with overflow-wrap: anywhere inside source lists.
  • Standalone links in section headers drop below the heading under 640px via the cluster.

Theming

Reads --color-fg-link, --color-fg-link-hover, --color-focus-ring. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
