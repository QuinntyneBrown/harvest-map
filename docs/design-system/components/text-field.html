Overview

Always inside a form field with a visible label. Search inputs carry a leading icon and live in toolbars and the topbar.

Anatomy

  1. Label--text-label
  2. Input40px, 1px --color-border-strong
  3. Help--text-body-sm muted

Variants

Variants change emphasis or content, never meaning.

Search with icon; e-mail.
HTML
<form class="search" role="search" style="width:16rem;"><label class="visually-hidden" for="tf-s">Search</label><svg class="icon" aria-hidden="true" viewBox="0 0 24 24"><circle cx="11" cy="11" r="7"/><path d="m20 20-3.5-3.5"/></svg><input class="input" id="tf-s" type="search" placeholder="Search"></form><label class="visually-hidden" for="tf-e">E-mail</label><input class="input" id="tf-e" type="email" value="naomi@harvestmap.app" style="width:16rem;">

Responsive behaviour

  • Fields are full width of their column; two-column grids collapse to one under 640px.
  • 16px text prevents iOS zoom.

Theming

Reads --color-border-strong, --color-bg-surface, --color-focus-ring, --color-danger-solid, --color-bg-surface-sunken, --control-height-md. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).

Both themes
