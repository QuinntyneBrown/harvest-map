Responsive behaviour

  • ≥ 640px: grid (check, mark, body, end).
  • < 640px: flex-wrap; end group moves to its own line, right-aligned.

Theming

Reads --color-accent-subtle, --color-fg-accent, --color-fg-muted. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
