Score ring

Impact score 0–100 drawn with an animated conic-gradient (@property --score). Rank 1 is gold.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Impact = reach × severity × tractability. Fills from 0 on entry.

Anatomy

  1. Track--color-bg-subtle-hover
  2. FillAccent, gold for rank 1
  3. NumberTabular

Variants change emphasis or content, never meaning.

Theming

Reads --color-accent, --color-warning-icon, --color-bg-subtle-hover. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
