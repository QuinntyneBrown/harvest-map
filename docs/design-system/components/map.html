Map

Dot-matrix world (SVG mask, theme-coloured) with pulsing pins and anchored popovers.

Overview

Equirectangular 2.4° dot grid. Organisations without a single home are listed below instead of pinned.

Anatomy

  1. LandDot mask, --color-fg-subtle at 35%
  2. Pin12px core + ripple
  3. PopoverAnchored

Variants

Variants change emphasis or content, never meaning.

VerifiedUnverified
Legend: verified filled, unverified ring.
HTML
<div class="map__legend" style="margin:0;"><span><i></i>Verified</span><span><i class="unverified"></i>Unverified</span></div>

Sizes

2:1, full width.

States

Pointer and focus states are forced with data-state; real pages use the pseudo-classes.

VariantPinUnverifiedSelected
Pin

Both themes

Responsive behaviour

  • Popover docks under the map under 640px.

Theming

Reads --color-accent, --color-warning-icon, --color-fg-subtle, --duration-loop-slow. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).

Both themes

Accessibility

Role and pattern

Pins are buttons; a text list of placed and unplaced organisations sits beside the map.

Keyboard

KeyAction
TabPin to pin
EnterOpen popover
EscClose

Focus

Pin scales 1.4 on focus.

Labelling

“Name, city”.

Contrast

Pin on surface

Motion

Pin ripple staggered; off with reduced motion.

Touch

24px targets; dense clusters spread on zoom.

Content

  • Say where the gaps are in one sentence below the map.
