Overview

Use tabs when the panels are peers of one object. For filtering a list, use chips.

Anatomy

  1. Tab44px, label + count
  2. Indicator2px accent underline

Variants

Variants change emphasis or content, never meaning.

Underline tabs.
HTML
<div class="tabs" role="tablist" aria-label="Sources"><button class="tab" role="tab" aria-selected="true" type="button">Verified</button><button class="tab" role="tab" aria-selected="false" tabindex="-1" type="button">Pending</button><button class="tab" role="tab" aria-selected="false" tabindex="-1" type="button">Rejected</button></div>

Sizes

One size.

States

Pointer and focus states are forced with data-state; real pages use the pseudo-classes.

Responsive behaviour

  • Scroll horizontally under 640px; no wrapping.

Theming

Reads --color-fg-accent, --color-accent. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
