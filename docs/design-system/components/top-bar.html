Overview

Harvest Map has no sidebar on desktop; the top bar holds navigation. Under 768px the links move into the navigation drawer.

Anatomy

  1. BrandWheat mark + name (name hidden under 1024px)
  2. Primary navNav links; current = accent-subtle
  3. UtilitiesSearch ⌘K, bell with count, avatar

Responsive behaviour

  • < 768px: menu button, mark, search, bell, avatar.
  • 768–1023px: inline nav, small labels, mark only.
  • ≥ 1024px: full brand and 24px gaps.
  • Shadow appears via @container scroll-state(stuck: top) (Chrome 133+).

Theming

Reads --color-bg-surface, --layout-topbar-height, --color-accent-subtle, --color-fg-muted. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
