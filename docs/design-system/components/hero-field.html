Hero field

The WebGPU grain field behind the home hero. Thins out on the left so the title sits on clean canvas.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

4,000 grains, compute + render passes in WGSL, tinted from --color-accent. Falls back to a slow conic gradient without WebGPU; stills under reduced motion.

Anatomy

  1. CanvasBleeds into margins, masked to fade down
  2. TitleDisplay, max 14ch

Variants

Variants change emphasis or content, never meaning.

data-gpu="on" (WebGPU)data-gpu="off" (CSS fallback)
Two renderers.
HTML
<span class="tag">data-gpu="on" (WebGPU)</span><span class="tag">data-gpu="off" (CSS fallback)</span>

Sizes

Hero height; canvas covers it.

States

Pointer and focus states are forced with data-state; real pages use the pseudo-classes.

VariantWebGPUFallbackReduced motion
FieldDrifting grainsTurning gradientSingle still frame

Both themes

Responsive behaviour

  • Resolution follows devicePixelRatio (max 2) via ResizeObserver.

Theming

Reads --color-accent, --duration-ambient. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
