Form layout

One column, 24px between fields, error summary first, actions last.

Overview

Forms live in a 44rem card. Two- and three-column grids are used only for short related fields (City/Country, Reach/Severity/Tractability).

Anatomy

  1. Error summaryLinks to each field; receives focus
  2. Fields--space-6 apart
  3. ActionsRight-aligned; saved status left

Variants

Variants change emphasis or content, never meaning.

Success: inline saved status.

Sizes

Max width 44rem.

States

Pointer and focus states are forced with data-state; real pages use the pseudo-classes.

VariantDefaultSubmittingInvalid
ActionsFix 2 things

Responsive behaviour

  • Multi-column field grids collapse to one column under 640px.
  • Actions wrap; primary stays last.

Theming

Reads --color-danger-solid, --space-6. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
