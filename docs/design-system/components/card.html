Card

Overview

Groups one thing. Clickable cards have one real link (the name); the lift is decoration.

Anatomy

  1. Surface--color-bg-surface, --radius-lg
  2. Border1px --color-border-default
  3. Padding--space-6 (32 in forms)

Variants

Variants change emphasis or content, never meaning.

Padding --space-6 default; --space-8 for answer and form cards.

Responsive behaviour

  • Full width under 640px; grids use auto-fill minmax(19rem, 1fr).

Theming

Reads --color-bg-surface, --color-border-default, --radius-lg, --shadow-1, --shadow-2. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
