Overview

Use native <select>. For long or searchable lists use the palette pattern or a filtered radio list as in Link problem.

Anatomy

  1. LabelAbove
  2. Control40px, chevron drawn with gradients

Variants

Variants change emphasis or content, never meaning.

Inline small, for toolbars.
HTML
<label class="field" style="flex-direction:row;align-items:center;gap:var(--space-2);"><span class="field__label">Sort</span><select class="select input--sm" style="width:auto;" aria-label="Sort"><option>Impact</option></select></label>

Sizes

32 / 40px.
HTML
<label class="visually-hidden" for="se-s">S</label><select class="select input--sm" id="se-s" style="width:9rem;"><option>Small</option></select><label class="visually-hidden" for="se-m">M</label><select class="select" id="se-m" style="width:9rem;"><option>Medium</option></select>

States

Pointer and focus states are forced with data-state; real pages use the pseudo-classes.

Theming

Reads --color-border-strong, --color-fg-default. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
