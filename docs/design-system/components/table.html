Table

Tabular data with a sunken sticky header. Harvest Map prefers entity cards; tables are for imports and mappings.

Use for comparing columns (CSV mapping, exports). Lists of records use entity cards.

Responsive behaviour

Theming

Reads --color-bg-surface-sunken, --color-bg-subtle, --color-accent-subtle. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
