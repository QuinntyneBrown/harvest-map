Overview

Harvest Map uses it in the phone drawer, not as a permanent sidebar. It is the same .nav-link as the top bar.

Anatomy

  1. LinkIcon + label, 44px
  2. GroupOverline heading
  3. CountBadge with aria-label

Variants

Variants change emphasis or content, never meaning.

Responsive behaviour

Theming

Reads --color-accent-subtle, --color-fg-subtle. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
