Overview

Opens from the topbar search button, ⌘K or /. Groups results (Organisations, People, Actions) and turns a no-match into Ask the web.

Anatomy

  1. Input18px text, 48px tall
  2. Group headingOverline
  3. Item40px, icon, label, meta, optional kbd
  4. FooterKey hints

Variants

Variants change emphasis or content, never meaning.

No matches for “zebra”.
No results with a way out.

Sizes

One size: 36rem wide, 12vh from the top.

Pointer and focus states are forced with data-state; real pages use the pseudo-classes.

Responsive behaviour

  • Full width minus 16px under 640px; list max-height 50vh.

Theming

Reads --color-bg-surface-raised, --color-bg-subtle, --shadow-4. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
