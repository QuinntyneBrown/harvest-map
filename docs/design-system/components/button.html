Button

Buttons trigger actions. Five variants, three sizes, every state, a spring press and a halo on primary hover.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Use a button when activating it changes something: saves, runs research, deletes, opens a dialog. Use a link when it only goes somewhere. Harvest Map keeps one primary per view; in the mocks that is Ask the web, New, Save or the dialog's confirm.

  • Primary: the one action the view exists for.
  • Secondary (default look): every other action.
  • Ghost: toolbars, page-header actions like Import/Export, row actions.
  • Link: low-emphasis action inside text.
  • Danger: destructive confirmation inside a dialog only.

Anatomy

  1. Leading icon (optional)1.25em, inherits colour, aria-hidden
  2. LabelVerb phrase, sentence case
  3. Container--control-height-md, --radius-md (12px), 1px border

Variants

Variants change emphasis or content, never meaning.

Responsive behaviour

  • Never wraps its label; a cluster of buttons wraps instead.
  • Under 640px dialog footers keep buttons side by side; the confirm stays last (right).
  • Touch: primary mobile buttons use --control-height-lg (48px) or sit in a 44px target.

Theming

Reads --color-accent, --color-accent-hover, --color-fg-on-accent, --color-border-strong, --color-danger-solid, --control-height-md, --radius-md, --ease-spring-linear. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).

Both themes

Accessibility

Role and pattern

Native <button> (APG Button). Toggle buttons add aria-pressed; menu triggers add aria-expanded.

Keyboard

KeyAction
EnterActivate
SpaceActivate
TabMove to next control

Focus

Shared 2px ring, 2px offset, never removed. Dialogs autofocus the safe button, never the danger button.

Labelling

Visible label is the accessible name; icon-only buttons need aria-label and a tooltip.

Contrast

Label on primary
Label on danger
Secondary border on surface

Motion

Press scales to 0.98 with a spring; primary hover grows a 4px accent halo over --duration-base. Both vanish under reduced motion.

Touch

Hover halo is cosmetic; press feedback is the scale. Minimum 40px tall, 48px for large.

Content

  • Verb first: Run, Save, Delete organisation, never OK or Submit.
  • Name the count when acting on a set: Export 14 organisations, Import 312 rows.
  • Danger buttons name the thing: Delete organisation, not Delete.
