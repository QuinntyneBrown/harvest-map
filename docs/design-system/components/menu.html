Menu

A list of actions behind one trigger. Core component; the mocks have not needed one yet.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Use for overflow actions on a record (Archive, Duplicate, Delete) when the page header would otherwise carry more than three buttons.

Anatomy

  1. TriggerButton with aria-haspopup
  2. Surface--shadow-3, --radius-md
  3. Item32px tall, label + optional kbd

Variants

Variants change emphasis or content, never meaning.

Shortcuts, divider and danger item.
HTML
<ul class="menu" role="menu" aria-label="Example" style="position:static;"><li role="none"><button class="menu__item" role="menuitem" type="button">Edit<kbd>E</kbd></button></li><li role="none"><button class="menu__item" role="menuitem" type="button">Export</button></li><li class="menu__divider" role="separator"></li><li role="none"><button class="menu__item menu__item--danger" role="menuitem" type="button">Delete</button></li></ul>

Sizes

One size; items are 32px.

States

Pointer and focus states are forced with data-state; real pages use the pseudo-classes.

VariantDefaultHoverDisabled
Item

Both themes

Responsive behaviour

  • Under 640px a menu with more than five items becomes a bottom sheet (dialog).

Theming

Reads --color-bg-surface-raised, --shadow-3, --color-bg-subtle, --color-danger-fg. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).

Both themes

Accessibility

Role and pattern

APG Menu Button: aria-haspopup="menu", aria-expanded, role="menu/menuitem".

Keyboard

KeyAction
Enter / Space / ↓Open, focus first item
↑ ↓Move
EscClose, return focus
LetterType-ahead

Focus

Roving focus inside the menu; returns to the trigger.

Labelling

Trigger has a visible label; menu has aria-label.

Contrast

Item on raised surface
Danger item

Motion

Scales in from the trigger over --duration-fast.

Touch

Items grow to 44px under (pointer: coarse).

Content

  • Verbs, sentence case.
  • Destructive item last, after a divider.
