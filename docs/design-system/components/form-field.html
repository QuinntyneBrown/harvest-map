Overview

The wrapper every input uses. Optional fields say so in the label; required is the default.

Anatomy

  1. Label--text-label
  2. ControlAny input
  3. Error⚠ + text, --color-danger-fg
  4. Gap--space-1

Variants

Variants change emphasis or content, never meaning.

Optional marker.
HTML
<div class="field" style="width:16rem;"><label class="field__label" for="ff-b">Founded <span class="optional">(optional)</span></label><input class="input" id="ff-b" inputmode="numeric"></div>

Sizes

Inherits the control size.

States

Pointer and focus states are forced with data-state; real pages use the pseudo-classes.

Theming

Reads --color-fg-default, --color-fg-muted, --color-danger-fg, --space-1. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).
