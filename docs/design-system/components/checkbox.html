Checkbox

Independent on/off choices and row selection.

Overview

Use .choice for labelled checkboxes in forms and .row-check for selecting cards in lists.

Anatomy

  1. Box20px, --radius-xs
  2. LabelBody text
  3. DescriptionMuted small

Variants

Variants change emphasis or content, never meaning.

Look for
Group in a fieldset; bare row check.
HTML
<fieldset><legend>Look for</legend><label class="choice"><input type="checkbox" checked><span class="choice__text">Organisations</span></label><label class="choice"><input type="checkbox"><span class="choice__text">People</span></label></fieldset><label class="row-check"><input type="checkbox" aria-label="Select FaithTech" checked></label>

Sizes

One size (20px box, 24px target).

States

Pointer and focus states are forced with data-state; real pages use the pseudo-classes.

VariantDefaultHoverFocusCheckedIndeterminateDisabled
Checkbox

Both themes

Responsive behaviour

  • Row checks are always visible on touch; on desktop they show on hover, focus or when any row is checked.

Theming

Reads --color-accent, --color-fg-on-accent, --color-border-strong. Dark theme comes from the semantic tokens; nothing in the component changes. To re-theme, override the semantic tokens in a [data-theme] block (see theming).

Both themes
