# Support

## How to get help

This project uses [GitHub Issues](https://github.com/QuinntyneBrown/harvest-map/issues) to track bugs and feature requests.

- **Bugs:** search the existing issues first. If yours isn't there, open a new issue with steps to reproduce it.
- **Feature requests:** open a new issue that describes the problem you want to solve.
- **Questions:** open an issue and add the `question` label.

## Security issues

Don't report security vulnerabilities in public issues. Follow the steps in [SECURITY.md](SECURITY.md).

## Support policy

Harvest Map is maintained on a best-effort basis. There is no guaranteed response time.
